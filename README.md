# WELLBE+ (Watch)

Circular smartwatch companion prototype for **WELLBE+**, designed for glanceable emotional check-ins, quick somatic resets, and wrist-first well-being cues paired with the mobile experience.

## Key Features

- **Glanceable Check-Ins:** Rapid, low-friction emotional state logging tailored for circular Google Pixel Watch viewports and short micro-interactions.
- **On-Wrist Somatic Resets:** Guided breathing and tactile regulation prompts accessible without pulling out a phone.
- **Cross-Device Companion Continuity:** Designed alongside `wellbe-mobile` to support seamless daily tracking across wrist and mobile surfaces.
- **Circular Viewport Ergonomics:** High-contrast dark UI, generous touch targets, and minimal cognitive load optimized for small round screens.

## Tech Stack & Design Direction

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Target Form Factor:** Circular smartwatch / Google Pixel Watch viewport
- **Design System:** High-contrast dark-mode UI with Material 3 / Wear OS-inspired visual cues
- **Authoring & Deployment:** Built with Google AI Studio and deployed on Vercel
